# 2026-11-09 research: CARVE + Where-to-Unmask + EB-Sampler + FlashProve -> CGBS

## Findings

### CARVE — Verified Expansion for Variable-Length Generation in Diffusion LMs (arXiv:2608.30922, Aug 2026)
Training-free variable-length decoding for masked diffusion LMs. A
standard masked-diffusion decoder fixes the canvas length before
generation; CARVE augments it with a *verified expansion* step: each
proposed canvas expansion is checked by measuring its effect on the
model's remaining predictive state (Jensen-Shannon divergence), asking
both whether additional space might be useful and whether inserting it
leaves the rest of the prediction intact. Gains on code and math
reasoning across Dream-v0-Instruct-7B, LLaDA-1.5 and LLaDA-8B-Instruct
(up to +4.27 HumanEval on Dream), at roughly half the FLOPs of
fixed-length decoding in some settings.
Diagnosis absorbed: a verifier can score candidate expansions, and
verification-guided search beats a fixed decoding schedule. Mechanism
NOT ported: CARVE verifies expansions against the model's *own*
predictive distribution (JS divergence) — self-referential; a
confidently-wrong model verifies its own mistakes. CGBS keeps the
diagnosis and replaces the mechanism (see below).

### Where-to-Unmask — Ground-Truth-Guided Unmasking Order Learning (arXiv:2602.09501)
Masked-diffusion generation couples two decisions per step: which
positions to unmask (where) and which tokens to place (what).
Heuristic orders (e.g. confidence margin) can degrade quality; the
paper defines Gt-Margin — the probability margin between the correct
token and its strongest alternative under ground truth — as an oracle
unmasking order, then trains a supervised learning-to-rank planner to
imitate it, improving reasoning accuracy without modifying the token
model.
Diagnosis absorbed: commit order is a decision in its own right, not
a side effect of confidence; the order that fills easy positions
first is measurably better. Mechanism NOT ported: the planner needs
training (and ground truth at train time). CGBS searches orders at
inference with no training and no learned planner — a beam over
commit orders, scored by certificate validity.

### EB-Sampler — Entropy Bounded Unmasking (Aug 2026)
Adaptive sampler for masked diffusion models: decides which tokens to
unmask and how many per step using an entropy bound that approximately
limits the dependence of unmasked tokens. Drop-in replacement, 2-3x
speedup on LLaDA and Dream on coding/math benchmarks without loss.
Diagnosis absorbed: unmasking decisions can be made jointly per step
rather than one fixed rule. Mechanism NOT ported: EB-Sampler is a
speed device walking one trajectory; CGBS spends *more* forward
passes (up to beam_width per round) to buy search, and says so in
the certificate.

### FlashProve (Anthropic, open-sourced 2026-11-02, Apache 2.0)
Zero-knowledge proof that an answer was generated by a committed set
of weights: proves *origin*, not correctness. 70-95x inference cost,
1,024-token context, greedy decoding only, ~18.8 MB proof per 1,024
tokens, CPU verification. Watch-tier only (already logged in the
2026-11-07 note): XIIV's certificates prove the *content* satisfies
a checkable property; FlashProve proves *who* said it. Different
axis, no adoption path — but the contrast sharpens XIIV's claim: a
certificate you can verify from the token list alone, with no 70x
overhead and no weights in the loop. The industry publishing a
proof-carrying direction at all is thesis confirmation, not a moat
threat.

### Also noted (watch tier, not adopted)
- Sampling-Dependent Fairness in Diffusion LMs (arXiv:2610.27584v2):
  bias scores in LLaDA/Dream shift >40% across sampling
  configurations. Honesty note for the whole sampler family: the
  sampler changes the measurement, not just the speed; sampler
  comparisons must be reported per-configuration, never as a bare
  model property.
- TDLM — Temporal Self-Conditioning (arXiv:2610.36940): each
  unresolved position attends to its own history of hidden states
  inside a frozen denoiser; up to 7.15x faster generation, +0.84%
  trainable parameters. Training-side; not adoptable without GPU
  retraining. Shelf.
- Formally-Verified Training and Runtime Validation for SLMs (ACM,
  Oct 2026): solver-enumerated formally-verified fine-tuning data
  (guarantee by construction) + tiered hybrid runtime checker
  (guarantee by verification) for healthcare SLMs. Adjacent
  confirmation that the field is converging on construction +
  verification; XIIV's certificates are the runtime-check tier,
  but theirs is OCL/Alloy for small models, not diffusion
  decoding. Background.

## What was built today: CGBS (xiiv/cgbs.py)

Certificate-Guided Beam Search. The first sampler in the family
that *searches* instead of walking one greedy trajectory: a beam
over commit orders, where each successor commits one (position,
token) and is admitted only if the independent verifier accepts
its canvas. Beam score is sum log-prob; certificate validity is a
hard filter, never a soft trade against likelihood — the deliberate
contrast with CARVE's self-referential JS scoring. Certificate
pruning taboos the pruned (position, token) run-wide (VRC
doctrine). Fail-closed: incomplete runs report completed=False
with masks remaining.

Pre-registered falsifiers in xiiv/tests/test_cgbs.py: F1 beam
rescues the trap stub (beam_width=4 completes, vanilla stalls,
safe 51 at position 4); F2 gate live (gate_rejects >= 1,
verified == expansions - prunes, final canvas clean); F3 final
soundness; F4 determinism; F5 budget; F6 width-1 == independent
greedy reference. KILL: F1 fails -> does not ship; F2/F3 fail ->
not actually certificate-gated -> kill.

Honest scope: tested on scripted models only, not yet evaluated
on a real checkpoint — same disclaimer as the rest of the family.
The 1B does not generate (0/5 gates at every checkpoint); no
sampler claim changes that.
