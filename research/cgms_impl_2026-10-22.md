# CGMS + partial-certificate gate — implementation record (2026-10-22)

Implements the 2026-10-20 daily-cycle pick (research/daily_research_2026-10-20.md):
LESS-2026's 3-gate stability sampler ported into `xiiv/diffusion.py`, plus
XIIV's fourth gate — partial-canvas certifiability.

## What shipped

- `partial_certificate_check(ids, constraints, mask_id, frozen=None)` in
  `xiiv/diffusion.py`, re-exported as `xiiv.contracts.partial_certificate_check`
  and `Contract.partial_certificate_check`. Sound in the fail direction:
  returns (False, reason) only when a violation is already unavoidable —
  anchor conflict, forbidden token filled, at_most cap exceeded, forbidden
  phrase completed in a fully-filled window, required occurrences missing
  beyond remaining fillable slots, order pairs violated or infeasible
  (window-feasibility on both sides). Never rejects a completable canvas.
- CGMS in `DenoisingState` (opt-in `cgms=True`; tunables cgms_tau_c=0.6,
  cgms_p_min=2, cgms_delta=0.1, cgms_topk=16): per-step top-1 persistence
  and top-K inter-step JS divergence history; on non-final steps, commits
  up to the step's existing budget of positions passing all four gates
  (deterministic top-1, stability order), with a most-stable-certifiable
  anti-stall fallback and deferral otherwise. Slot-reservation budget is
  inherited from the standard path, and the FINAL step always runs the
  standard path — completion and endgame guarantees are unchanged.
  Disabled automatically when a GCDD `guarantee` object owns commits.
  Stats in `state.cgms_stats`; commits/defers logged as interventions.
- Tests: `tests/test_cgms.py` — 18 tests (11 partial-check units,
  JS-divergence units, guarantee-preservation across seeds, determinism,
  stub-model commit path). Suite: test_cgms + test_contracts +
  test_contracts_v2 + test_glod + test_grow = 51/51 green.

## Measured (honest, toy testbed)

Tiny untrained model (d=64, 2 layers), length 24, 8-step budget,
constraints {required 10/20/30, forbidden 200, at_most 50:2}, 10 seeds:

- Validity: confidence path 10/10, CGMS 10/10 — guarantees are
  structural in both; CGMS neither helps nor harms validity here.
- Steps-to-complete: 8.0/8 both (budget-bound; no reduction measurable).
- CGMS behavior on this model: defers on every non-final step
  (cgms_stats seed 0: 7 defers, 0 commits) because the untrained
  model's top-1 is the mask token / unstable — the gates correctly
  refuse. The commit path is proven separately on a deterministic
  stub model with stable top-1s (commits > 0, canvas valid).

Verdict: mechanism implemented and gate-verified; payoff (LESS's
step-reduction) UNPROVEN on this testbed — same standing bottleneck as
GLOD gate 2 and CSM Phase C: the toy model's predictions are too
unstable for any allocation/stability signal to pay. Re-measure on the
trained XIIV-1B when blocks 5–7 land; do not bank a factor in the 100x
ledger before that.
