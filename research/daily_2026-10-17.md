## Top pick: Verity-Routed Composition (VRC) — deterministic verification-driven harness for the Proof Machine's composition policy

**What it is (SKILLFORGE paradigm).** A deterministic harness — not an agent — that synthesizes
compositions with a *formal oracle in the loop*. The verifier's structured error output is parsed
into categories that **deterministically select the next repair skill** (spec inference, invariant
generation, error diagnosis, code repair, spec strengthening). Termination is guaranteed by hard
iteration budget, stagnation detection, and rollback to the best-scoring candidate; soundness is
unconditional: a returned program verifies by construction. Succeeds in 2 iterations where ReAct
agents need 3–5 turns.

**Why it fits XIIV.** The Proof Machine spec (§4.4) explicitly defers the composition policy to
Phase 2: "learning the composition policy (from specification to primitive sequence) becomes the
next problem." SKILLFORGE is the missing Phase 2 algorithm: the COMP rule's interface check
(`γ(last(τ_f)) ⊆ { y | P_g(y) }`, §2.2) is *exactly* the structured formal oracle SKILLFORGE
exploits — its failures are localized to a single composition step, so they route repair
deterministically. Zero reasoning overhead, fully auditable, and the repair trail feeds the
intervention-rate metric — pure guarantee-native.

**Concrete implementation proposal (CPU-only, no training, no GPU, KBs of RAM).**
New reference module `research/proof_machine/vrc_harness.py`
(building on the Phase-1 library + kill-gate harness created today under
`research/proof_machine/`), operating on the 8 arithmetic primitives:

1. **Skill library** (atomic, deterministic): `SPECSPLIT` (decompose target postcondition into
   per-step sub-goals), `GENSEQ` (propose primitive sequence from sub-goals), `GENIFACE`
   (synthesize interface preconditions = the `∀y.(Q_f → P_g)` side of COMP), `REPAIRSTEP`
   (swap the primitive at the failing interface), `STRENGTHEN` (tighten a precondition to satisfy
   the interface inclusion), `WEAKEN` (loosen a too-strong Q_f that starves the next step).
2. **Harness loop:** state `(sequence, errors, diag, history)`; run interface checks; parse the
   failing check into one of ~6 categories (precondition violated, output escapes P_g, Q_f too
   strong/weak, depth blowup, stagnation) and route to exactly one skill; monotonic failure-count
   decrease required, else rollback to best-validated prefix (certificates of the prefix survive —
   composition never discards proven work).
3. **Tests:** synthesize sequences for target postconditions like `y = ((x+3)·2 mod 7)+1` from the
   spec alone; assert returned sequences compose with 100% certificate validity (§5.4 metric V(L))
   and bounded iterations (< 20 per depth-≤8 task).

**Honest novelty assessment: principled PORT with an original composition — not an invention.**
The verifier-routed-harness mechanism is published prior art (SKILLFORGE, 2026). XIIV's original
step: the oracle is the ∘ interface check (not a program verifier), routing preserves certificate
validity by construction (rollback keeps proven prefixes), and repair is keyed to Presburger
interface failures. Precedent: this is exactly how `guarantee_decode.py` handled LAVE — same
honesty framing. No zero-prior-art claim.

## Runner-ups (fit, but not today's pick)

- **GUARD (2410.06716):** proves guaranteed generation is impossible with AR training alone —
  adopt as a *thesis citation* for why XIIV pairs diffusion with inference-time guarantees. No code.
- **Register tokens (2609.16372):** +8.5 math / +19.5 code on LLaDA/Dream by carrying reasoning
  state in dedicated tokens across chunks. Candidate for carrying *certificate/interface state*
  across diffusion chunks — but needs training on the 1B; defer to GPU phase.
- **DSL-LLaDA:** continuous-embedding denoising adaptation of pretrained masked DLMs. Training
  recipe, not CPU-feasible here; SGBD already covers the low-resource training track.
- **1B-on-4GB stack (BAdam + offload + b1.58 + tied + chunked CE):** validates XIIV's SGBD
  direction (block-wise training on weak hardware); already covered by `xiiv/sgbd.py`.

## Explicitly ruled OUT today

- LAVE port — **already implemented** (`xiiv/guarantee_decode.py`, tests green). Re-porting it
  would duplicate work; noted here so no future run re-discovers it.
- Proof-Carrying Neuro-Symbolic Code (2504.12031), NeuralCert (2609.30296): post-hoc certification
  of neural outputs — the proof is external, not intrinsic to the computation. XIIV's bet is the
  opposite direction; cite only as contrast.
- LLM-guess-and-check synthesis loops (VerIbmc, NL2VC): neural proposes, verifier rejects —
  they fail *after* generation. VRC differs: the certificate is constructed, never searched.
