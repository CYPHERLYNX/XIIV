## Research sweep (18 sources scanned; claims from arXiv abstracts/full text)

### Masked diffusion LMs (decoding/sampling)
- **RPD — Reliable Parallel Decoding in MDLMs** (arXiv:2609.36452, UVA, Sep 2026, verified full text). Training-free decoding: commit predictions only when (a) stable across final layers (prediction persistence K_i + confidence-drop penalty r_i) and (b) cumulative upstream entropy under budget. Key diagnostic: high confidence at sequence end reflects formatting priors, not computed answers — confidence-based decoding commits wrong answers early (57%→72% accuracy via ordering constraints alone). On LLaDA + Dream math/code: highest throughput of compared samplers (2.4–6.1× vs default) with maintained/improved accuracy. CPU-feasible (no training; entropy arithmetic + layerwise argmax projections).
- **KLASS** (arXiv:2511.05664v2, KAIST). Token-level KL-stability sampling, 2.78× wall-clock, training-free. Abstract-only (PDF fetch timed out) — treat numbers as reported.
- **PC-Sampler** (arXiv:2508.13021). Position-aware calibration fixing early-commitment-of-boundary-tokens bias; 57.9% HumanEval / 76.4% GSM8K on Dream-v0-7B. Training-free.
- **LLaDA2.0** (arXiv:2512.15745v2, Dec 2025). AR→diffusion conversion to 100B MoE. Frontier-GPU only — no lever for this box.
- **DSL-LLaDA** (arXiv:2606.01024). Continuous embedding-space denoising; needs pretrained model + GPU.

### Guarantee-native / verified generation
- **PRoSFI** (arXiv:2603.29500, PKU/ByteDance). Model emits lightweight structured records per reasoning step (deps ≤5, formalized conclusion, inference rule); Lean4/Prover9/Z3 verify post-generation; process reward 1.0 = verified chain / 0.3 = right answer failed checks / 0.1 = formatted-but-wrong. Its record schema mirrors our certificate schema. Directly informative for Phase-2 composition-policy search (verify-or-penalize, sound-by-construction). Harness logic CPU-feasible; full RLVR needs GPU.
- **GenLimitLib** (arXiv:2609.36663). Lean-4 generation-in-the-limit library; kernel-checked proof success 48%→79%. Thesis evidence, not a lever.
- **LeetProof / ASE'26 certified synthesis**: reject under-specified specs before synthesis — matches our spec-reject posture (adopted in VRC today).

### Parameter-efficient training / optimizers
- **SCALE** (arXiv:2506.16659, 2025). Minimalist optimizer, 35–65% of Adam's memory, matches Adam/Muon 60M–1B (1B: 13.49 ppl at 2.81G vs Adam 13.30 at 8.04G). Drop-in for LoRA/SGBD block training. CPU-feasible. Abstract/snippet only (PDF timed out) — numbers reported, not verified.
- **Adam-mini** (arXiv:2406.16793v7). One LR per Hessian block; ≥90% of Adam's v eliminated, 45–50% memory saved. Superseded by SCALE for our use (better 1B memory/perplexity frontier).
- **ChainDoRA** (arXiv:2609.25058, Sep 2026). Tensor-Train factorization of DoRA's directional branch: ~10× fewer adapter params (5.35M vs 56M) at matched/better accuracy on LLaMA-7B reasoning; TT rank is the dominant capacity knob. CPU-implementable but thin validation (7B-only, reasoning-only, TT optimization risks uncharacterized) — riskier than SCALE.
- **Muon scalability** (arXiv:2502.16982). GPU-scale; no new CPU lever.

## Top pick (queued for the diffusion track): Certified Parallel Commitment (CPC)

Adapt RPD (2609.36452) as XIIV's diffusion sampler with a guarantee-native twist:
layerwise stability gate (S_i from persistence K_i + drop penalty r_i) + cumulative
upstream entropy budget, PLUS a machine-checkable **commitment certificate** per
decoding step (positions committed with their stability evidence, budget
consumption, deferred positions with reasons, abstain flag when nothing certifiable
remains). The independent verifier re-checks certificates offline — decoding becomes
proof-carrying; abstention replaces hallucination. Falsifiable in-house eval:
accuracy-at-fixed-steps vs vanilla confidence decoding on arithmetic traces.

**Novelty (honest):** principled PORT of RPD's core + genuine invention candidate in
the certificate/abstention layer — no published work couples masked-diffusion
parallel commitment with proof-carrying certificates and verifier re-checking.
Queued for a future run (`xiiv/diffusion.py`); NOT implemented today (standing
priority is the Proof Machine track).

## Part B (implemented today): VRC — Verity-Routed Composition

Yesterday's queued Phase-2 candidate, built as `research/proof_machine/vrc_harness.py`
(~470 lines) + `test_vrc.py` (8 test groups, all green):

- Deterministic SKILLFORGE-style harness: spec `y = E(x0)` → verified primitive
  sequence. Oracle = interface check + independent certificate verifier + exact
  symbolic target equality. Failures route deterministically (only
  `interface-fail` continues via REPAIRSTEP with a monotone taboo; everything else
  halts LOUD: `spec-rejected`, `target-mismatch`, `cert-invalid`,
  `neural-divergence`, `repair-exhausted`, `budget-exhausted`).
- Key lemma documented and implemented as `realize()`: the spec language is larger
  than the trace language — `add(E,c<0)` → NEG sandwich, `mul(E,k<0)` →
  `neg(mul(E,-k))`, constant targets rejected (no op discards x0; induction over RULES).
- Constructive planner with a factoring peephole (`k*E2+c`, `k|c` → plan `E2+c/k`
  then `MUL_k` — shorter certificates; e.g. `((x0+3)*2 mod 7)+1` →
  `[ADD_3, MUL_2, MOD_7, ADD_1]`).
- 7/7 synthesis targets succeed in 1 iteration each (depths 3–11), every probe's
  certificate verifies, concrete == symbolic; 7/7 out-of-closure specs rejected
  loud with the exact cause; fault injection (zeroed MOD_7) → `neural-divergence`
  naming the op, no certificate shipped; simulated Phase-2 interface failure →
  REPAIRSTEP reroutes (`[MUL_2, ADD_3]` → `[MUL_2, ADD_1, ADD_1, ADD_1]`) and the
  repaired composition still verifies.
- Honest framing kept: interface leg vacuous in Phase 1 (executed, not skipped);
  STRENGTHEN/WEAKEN are documented Phase-2 no-ops; RPD port attribution recorded above.
