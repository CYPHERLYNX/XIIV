## Research sweep (12 sources scanned; claims from abstracts/full text as noted)

### Masked diffusion LMs (decoding/sampling) — the sampler family keeps growing
- **PSD — Parallel Speculative Decoding** (arXiv:2605.15609, May 2026, CityU/Huawei). Training-free; improves inference on TWO axes: spatial (adaptive multi-token unmasking per step) + temporal (collapse multiple denoising steps into one batched verification call). Hierarchical acceptance keeps the deepest draft consistent with updated predictions. Up to 5.5× tokens/forward pass on 3 dLLMs, accuracy comparable to greedy decoding. CPU-feasible (confidence arithmetic + one verification pass).
- **LESS — Mutual-Stability Sampling** (arXiv:2606.16908, MBZUAI/Ecole Polytechnique). Training-free adaptive sampler framing token commitment as an ONLINE STOPPING problem: unmask only when top-1 confidence is high AND top-1 persists across recent steps AND the predictive distribution is stable under top-K inter-step Jensen-Shannon divergence. 72.1% fewer reverse steps on Dream-7B / LLaDA-8B / LLaDA-1.5-8B across 7 benchmarks. The stopping-problem framing maps directly onto CPC's commit/abstain decision.
- **DMax / OPUT** (arXiv:2604.08302). On-Policy Uniform Training: noisy inputs sampled ON-POLICY from the model's own predictive distribution (not random vocab tokens) — closes the train/inference gap for uniform diffusion; plus SPD soft parallel decoding (soft embeddings interpolated by confidence). GSM8K TPF 2.04→5.48 on LLaDA-2.0-mini.
- **Prior-art honesty note — DMax/OPUT vs our OSCD** (invented 2026-10-13, `xiiv/onpolicy_distill.py`): convergent mechanisms, distinct settings. OPUT trains uniform-diffusion models on-policy end-to-end; OSCD embeds on-policy self-correction INSIDE SGBD block distillation (grown-from-seed, independent full-gradient blocks, cached teacher activations, masked discrete diffusion, CPU-only 7GB). Related, not identical; neither invalidates the other. Recorded so the lineage is clean.
- **TRIMS** (arXiv:2604.00666). Trajectory-ranked masked supervision: AR teacher estimates token difficulty in one teacher-forcing pass → hard-to-easy masking order. Training recipe, GPU-scale; curriculum idea only for us.

## Top pick (IMPLEMENTED today): proof-carrying conditionals (IFZERO)

Spec §5.6 task 2, the standing priority's direct next step — and today's research independently converges on it: GridCoder-2 shows execution-verified compositional PROGRAMS (with control flow, not just chains) are what generalize OOD; ABPR shows verifiable sub-problems + derivation traces are the working pattern.

**What it is:** `IFZ(cond, then, else)` — the guard program's NEURAL value decides the branch (0 → then); the taken branch runs on the pre-guard value; the certificate carries the guard trace + branch decision + taken-branch sub-trace. Preconditions become NON-VACUOUS for the first time: P_then(c):=(c==0), P_else(c):=(c!=0) — the ∀y.(Q_f→P_g) interface check now does real routing work (Phase-1's was P=true). A neural divergence at a guard halts LOUD, naming the condition — the VRC doctrine, extended to branch points. The independent verifier re-derives the guard symbolically and requires agreement with the neural value (B1–B4), so a diverged guard can never ship a certificate even if the prover-side halt were bypassed.

**Novelty (honest):** genuine EXTENSION of the in-house framework, not a port. Prior-art relationship noted, not hidden: the Hoare-logic IF rule and proof-carrying code are decades old; the novel instantiation is neural-guard-decides + symbolic-verifier-re-derives + divergence-halts-loud inside a learned-primitive compositional loop. No published work couples abstract-interpretation branch certificates with neural primitive execution this way (to our knowledge; not a legal-clearance claim).

**Falsifiable gate:** conditional depth sweep, depths {1,2,4,8,16,32,64,100} × 1000 fresh programs (taken-path primitive count; equal branch lengths so taken==max path). Pre-registered PM-only PASS: A_CIF(100) ≥ 90%, flat OLS slope, V_CIF = 100% all depths. KILL: <70%, significant negative slope, any cert failure. Baseline separation QUEUED (fair comparison needs the transformer retrained on the conditional program encoding — new token types for IFZ structure; ~36 min Phase-1-class cost; scheduled as follow-up, not silently dropped).
