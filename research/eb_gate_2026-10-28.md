## Pick: entropy-bounded certificate-gated commitment

CGAU (in-repo) already gates each position by certificate + margin, with
recovery and re-masking — but it bounds nothing about the *joint* entropy of
one step's commits. The EB gate closes exactly that gap: commit positions in
ascending-entropy order, only certifiable top-1 tokens, while
`sum(H) - max(H) <= gamma`. First commit always satisfies the bound
(value 0), so progress is guaranteed whenever a certifiable top-1 exists.

This is XIIV's own composition, not a port: the entropy bound is EB-Sampler's
mechanism shape, but the gating level is XIIV's semantic proof certificate
(EB-Sampler has no certificates; CGAU has no joint bound). Prior art is cited
in `xiiv/eb_gate.py`, not copied as mechanism.

## Implementation

- `xiiv/eb_gate.py` — stdlib-only selector (`select_commits`), no model, no
  torch, no checkpoint load. Top-1 only in v1 (CGAU already owns the top-k
  scan); uncertifiable top-1 positions stay masked (fail-closed).
- `tests/test_eb_gate.py` — 8 tests, deterministic + 300-instance fuzz.
  Result 2026-10-28: **8/8 pass**. All four pre-registered falsifiers hold:
  F1 certificate soundness, F2 bound, F3 progress, F4 ascending prefix.
  No kill condition triggered.

## Honest limits (what this is NOT)

- NOT wired into any sampler or generation path. Wiring changes generation
  behaviour and is owed a real-model evaluation (assembled 1B, GPU) first.
- NO model-quality claim: the fuzz suite proves selector properties on
  synthetic distributions, not better XIIV generations.
- The joint-entropy reduction vs "commit all certifiable" is a property of
  the bound (a subset with lower joint entropy by construction), not a
  measured generation improvement. No number is claimed for it here.
