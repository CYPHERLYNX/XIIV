# Probe 2 results — Conservation Reaction Substrate: rule-discovery reality check

**Date:** 2026-10-18 ~20:00 IST. **Script:** `research/reaction_probe2.py`
(runnable, numpy + stdlib, ~12s CPU per run; run with `nice -n 10`).
Run it to reproduce every number below. Optional flag `--fix-k` runs the
structure-only ablation described under "Ablation".

## What was tested

The second unproven transfer from the 8am verdict: can library learning
**discover** reaction rules in the vast rule space?

Continuous relaxation of the soup, exactly per the probe spec:
- soup = count-vector `x` in R^6 over terms `[a, c, d1, d2, d3, d4]`
  (`d1..d4` = inert distractors, must be ignored).
- rules = stoichiometric matrices: `A` (reactants, 6x4), `B` (products, 6x4),
  `k` (rates, 4); mass-action rates `rate_r = k_r * prod_i x_i^{A[i,r]}`;
  discrete steps = Euler integration, 20 steps of dt=0.02.
- Target rule (known, so success is checkable): the catalyzed doubling
  `a + c -> 2a + c`. The catalyst `c` is REQUIRED but CONSERVED — the learner
  must distinguish "consumed" from "required-but-conserved". (A plain `a -> 2a`
  would be learnable by mere growth-curve fitting; the catalyst version is the
  actual discovery challenge.)
- Data: 64 train / 32 held-out `(soup_before, soup_after)` pairs, targets
  generated by the true rule, ~70% reactive pairs.
- Optimizer: Adam (lr=0.03) on softplus-parametrized `(A,B,k)` (positivity is
  structural), L1 sparsity prior 1e-3 on all entries (chosen a priori),
  gradient-norm clip 5.0. Analytic backprop through the Euler rollout;
  gradients verified against finite differences (worst relative error 1.2e-07).

PASS criteria (fixed BEFORE running): held-out relative RMSE < 0.05, best
learned rule cosine-similarity to target `(A,B)` structure > 0.85, all other
rules' `k` < 10% of the best rule's `k`, learned vector field within 10% of
true on random states, and no identity-collapse (learned change >= 50% of true
change on reactive pairs). Max 5000 steps.

## Failure mode (exact)

**Gain explosion, then chaotic attractor.** In the first ~400 steps the
optimizer discovers that scaling up rates `k` reduces MSE on reactive pairs
faster than discovering stoichiometric structure (gain directions dominate
structural directions in the loss landscape). Rates blow up 10-15x, the Euler
rollout goes stiff/chaotic (state clip at 50 engages), gradients through the
chaotic rollout become uninformative, and the system settles into a bad
attractor: loss ~80, all 4 rules active with large rates, stoichiometry fitted
to noise (distractor-latching). L1 = 1e-3 is orders of magnitude too weak to
pull the system back once it is in this regime.

## Ablation (structure-only: k frozen uniform at 0.5, learn A,B only)

Run to test whether the failure is just the gain degree of freedom.
**Result: DIVERGED — loss non-finite (NaN) at step 649.** The mass-action
exponents themselves are dynamically unstable under gradient descent:
increasing an exponent `A[j,r]` increases the rate super-exponentially
(`rate ~ x^A`), a positive-feedback loop the loss rewards locally on reactive
pairs until the rollout explodes. The pathology is structural to learning
mass-action exponents through an Euler rollout, not an artifact of the rate
parameters.

## Verdict: KILL (robust)

The spec'd mechanism — gradient descent on stoichiometric matrices in a
mass-action continuous relaxation with a sparsity prior — does not discover
reaction rules. Two distinct structural failure modes (gain explosion into a
chaotic attractor; exponent instability to NaN in the ablation), both within
the probe's compute budget. This is a failure of the *mechanism*, verified with
correct gradients (1.2e-07 vs finite differences).

## What this does and does not imply — read carefully

1. **Killed:** gradient-based rule discovery in the mass-action continuous
   relaxation, as specified. Any future writeup must not present this
   mechanism as viable.
2. **NOT killed:** library learning as a component of the substrate. Note the
   honest asymmetry: DreamCoder — the cited prior art for library learning —
   discovers abstractions by **discrete enumerative search + compression**,
   not by gradient descent on continuous rule matrices. This probe's negative
   result redirects the design toward the DreamCoder-like discrete mechanism,
   which was always the closer analogy. The "compounding growth law" story
   survives only in that discrete-search form, which is a weaker and more
   standard claim than continuous rule discovery.
3. **Consequence for the verdict:** the 8am verdict's learning half ("the
   system grows a library of certified reaction rules... so cost per task
   decreases monotonically") currently has no demonstrated discovery engine.
   Probe 1 validated the execution half (sharing discipline). Until a
   discrete-search discovery probe passes, the verdict stands on one leg.
   Recommended next probe: enumerative/combinatorial search over small
   stoichiometric matrices scored by compression gain (DreamCoder-style),
   which sidesteps both failure modes above by construction.

## Process notes (honest)

- During development the analytic backprop initially disagreed with finite
  differences (worst relative error 0.89). Root cause found and fixed: the
  MSE gradient was `2(x-y)/N` but `np.mean` divides by `N*D` — off by exactly
  D=6, confirmed by direct numeric check of the adjoint states. Post-fix
  agreement is 1.2e-07. The KILL numbers above are from the corrected code.
- No hyperparameter tuning was performed after seeing results. The single
  ablation (`--fix-k`) was pre-declared as a diagnostic, not a rescue attempt;
  it failed harder (NaN), which strengthens rather than weakens the KILL.
- The distractor-latching in the final matrices is fitting-to-noise inside a
  chaotic regime, not evidence of any real signal — reported as-is, not
  interpreted further.
